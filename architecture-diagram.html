Executive Oracle - Salvi round 2 build

One store, two paths, a session boundary that actually holds

Uploading a PDF writes chunks into Qdrant tagged with that session's id. Asking a question runs a LangGraph agent that can only ever read chunks carrying that same id back out - a different session's uploads sit in the same collection but are structurally invisible.
